### 🚀 Dự án & Code yêu thích

**Bảng thống kê dự án Game cá nhân:**

| Tên Dự án | Thể loại | Trạng thái | Nền tảng |
| :--- | :---: | :---: | ---: |
| Chuyến Xe Bão Táp | Đua xe 3D | Đang phát triển | PC |
| Khối Vuông Kỳ Diệu | Roblox | Lên ý tưởng | Roblox |

**Cập nhật logic tăng tốc trong bản Patch mới nhất (Java OOP):**
```diff
public class RacingCar {
    private int speed;
    
    public void accelerate() {
-       this.speed += 5; // Tốc độ cũ quá chậm, thiếu kịch tính
+       this.speed += 10; // Đã buff tốc độ để phù hợp vật lý
        System.out.println("Vroom! Tốc độ hiện tại: " + this.speed);
    }
}
```
